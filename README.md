## MCP Tools Exposed
- `calculate_apob_apoa1_ratio`: Compute ApoB / ApoA1 atherogenic ratio to predict coronary heart disease plaque burden independent of LDL-C.
- `audit_ldl_apob_discordance`: Detect discordance between standard LDL-C and atherogenic particle count (ApoB) indicative of insulin resistance.
